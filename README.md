## 📱 소개

> **수박 고르기가 어려운 사람들을 위해, '통통통' 두드리는 소리로 AI가 숙성도를 예측하는 iOS 앱 - 통통통🍉**

## 🛠 기술 스택

- **iOS**
    
    - Swift / SwiftUI / UIKit
    
    - MVVM Architecture
    
    - AVFoundation
    
- **Backend**

## 🌟 주요 기능

1. 수박을 손 끝으로 3번 두드려 '통통통' 소리를 녹음한다.
2. 녹음된 소리를 통해 잘 익은 수박 / 덜 익은 수박 / 많이 익은 수박을 감별한다.
